Nvidia seeks two-element coverage of the step that tells an agent which data source to use

2026-09-10Filings

United States Patent Application Publication No. 2026/0267897 A1, Nvidia Corporation, "Automated Generation of Data Source Descriptions for Agentic Workflows," published September 10, 2026, filed August 20, 2025, claiming priority to United States Provisional Application No. 63/768,550, filed March 7, 2025

Claim 1 recites a system with processing circuitry to query a data collection with a zero-vector to retrieve a subset of data from the data collection, and to generate, using a machine learning model, a summary of the data collection based at least on the subset of data. In plain terms, the system probes a vector database with an all-zeros query embedding, which returns an arbitrary rather than a semantically targeted sample, and then has a model write a description of what the whole collection holds. That description is what an agent later reads when deciding which data source a task should be routed to. The claim has two elements and is not limited to large language models, to any particular agent framework, to retrieval augmented generation, or to text. It was one of six Nvidia applications published the same day, another of which, Publication No. 2026/0267835 A1, claims using agreement among multiple retriever models as a substitute for human labeling when selecting a filter for synthetic training data.

What it changesThis is the automatic data source description step that sits in most agentic data stacks, claimed at a breadth that will read on a great deal of ordinary practice if it issues near its published scope. Any company building agent orchestration over its own data should put this publication in front of whoever runs freedom to operate, and should check whether its own equivalent step is described anywhere in its own filings. The wider signal is that the company selling the hardware underneath everyone's agents is filing on the orchestration software above it, while the two laboratories with the most valuable models hold almost nothing: as indexed by Justia Patents on September 21, 2026, the entire United States portfolio of Anthropic, PBC runs to fourteen documents and that of OpenAI OpCo LLC to four.
